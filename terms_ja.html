第1章 総則

第1条（目的）

本規約は、Patrick Games KR（以下「当社」）が提供するモバイルゲーム「伝説の鍛冶場の末裔」（以下「本ゲーム」）の利用に関し、当社と利用者の権利、義務および責任その他必要な事項を定めます。

第2条（定義）

  1. 「利用者」とは、本規約に従って本ゲームを利用する者をいいます。
  2. 「アカウント」とは、本ゲームを初めて起動した際に自動的に作成される匿名の識別子と、それに紐づくゲーム記録をいいます。本ゲームは会員登録を行いません。
  3. 「アカウントコード」とは、アカウントを区別するためにゲーム画面に表示される文字列をいいます。
  4. 「有料商品」とは、利用者がGoogle Playの決済で購入する「広告削除」、「名匠の名札」、固有名などの商品をいいます。
  5. 「ランキング」とは、利用者のゲーム記録を他の利用者と比較して表示する機能をいいます。
  6. 「不正プレイ」とは、第12条で禁止する方法で本ゲームを利用することをいいます。

第2章 利用契約とサービス

第5条（利用契約の成立）

  1. 利用契約は、利用者が本ゲームをインストールし、本規約に同意した上でゲームを開始した時に成立します。
  2. 本ゲームは13歳以上の方を対象としています。
  3. 本規約の施行前から本ゲームを利用している利用者には、ゲーム内のお知らせで本規約を告知し、利用者が本規約に同意して利用を続けた時から本規約を適用します。

第6条（サービスの内容）

  1. 当社は、ゲームプレイ、ランキング、ゲーム内のお知らせなど、本ゲームに関する機能を提供します。
  2. 本ゲームは基本無料で、広告が表示されることがあります。一部の機能は有料商品として提供します。
  3. 広告を視聴して受け取る報酬は、広告の視聴を終えた場合に付与します。ネットワークに接続されていない、広告ブロック機能を使用している、表示できる広告がない、1日の広告視聴上限に達したなどの理由で広告を視聴できない場合は、報酬が付与されないことがあります。
  4. 欧州経済領域・英国など広告への同意が必要な地域の利用者は、ゲームの設定の「広告のプライバシー設定」で広告への同意を変更できます。
  5. ゲームの進行データは利用者の端末に保存されます。アプリの削除、端末の初期化、機種変更の際に失われることがあります。
  6. ランキング、週間ランキング、称号の集計基準と報酬はゲーム内で案内します。ランキングでは、利用者のニックネーム（または購入した固有名）とゲーム記録が他の利用者に公開されます。

第7条（サービスの変更・中断・終了）

  1. 当社は、運営上・技術上の必要に応じて本ゲームの内容（バランス、コンテンツ、報酬など）を変更することがあり、重要な変更はゲーム内のお知らせで告知します。
  2. 当社は、メンテナンス、設備の障害、天災など、やむを得ない場合にサービスの提供を一時的に中断することがあり、可能な限り事前にお知らせします。
  3. 当社が本ゲームのサービスを終了する場合、終了日の30日前までにゲーム内のお知らせとウェブサイトで告知します。
  4. サービス終了時に未使用または利用期間が残っている有料商品は、関係法令および韓国の「コンテンツ利用者保護指針」に従って払い戻します。当社は、終了日以降30日以上、払い戻しのお問い合わせを受け付けるメール窓口を運営します。

第3章 有料商品

第8条（有料商品と決済）

  1. 有料商品の内容と価格は、ゲーム内の購入画面に表示します。
  2. 決済はGoogle Playの決済システムで行われ、決済手段や決済限度額などはGoogleのポリシーに従います。
  3. 有料商品は購入したアカウントでのみ使用でき、他人に譲渡または販売することはできません。
  4. 購入した有料商品は、アプリの再インストールや機種変更の後も、本ゲームが提供する復元機能で再び使用できます。

第9条（申込みの撤回と返金）

  1. 利用者は、有料商品を購入した日から7日以内に申込みの撤回（返金）を求めることができます。
  2. ただし、韓国の「電子商取引等における消費者保護に関する法律」で申込みの撤回を制限できると定める場合には、申込みの撤回が制限されることがあります。この場合、当社は購入前に利用者がその旨を知ることができるよう表示します。
  3. 返金は、Google Playの返金手続きまたは当社へのメールで求めることができます。メールで求める場合は、Google Playの注文番号（GPAで始まる番号）をお知らせください。当社は決済履歴を確認した上で処理します。
  4. 当社は、返金の求めが正当な場合、決済履歴を確認した日から3営業日以内に返金手続きを行います。
  5. 返金された有料商品の効果は失われます。固有名は返却され、無料のニックネームに変わります。
  6. 当社の責めに帰すべき事由により有料商品を利用できなかった場合、当社は同じ商品を再提供するか、決済金額を返金します。

第10条（過誤納金の返還）

  1. 過誤納金が発生した場合、当社は決済と同じ方法で返還します。同じ方法で返還できない場合は、事前にお知らせした上で、利用者が選択した方法で返還します。
  2. 当社の責めに帰すべき事由により過誤納金が発生した場合、当社は手数料などにかかわらず過誤納金の全額を返還します。利用者の責めに帰すべき事由により発生した場合、返還にかかる費用は合理的な範囲で利用者が負担します。
  3. 当社が過誤納金の返還を拒否する場合は、料金が正当に請求されたことを当社が証明します。

第11条（未成年者の決済）

  1. 未成年者が有料商品を購入するには、法定代理人の同意が必要です。
  2. 法定代理人の同意なく行われた未成年者の決済は、未成年者本人または法定代理人が取り消すことができます。
  3. ただし、未成年者が成年であると偽った場合や法定代理人の同意があるかのように信じさせた場合、法定代理人が処分を許した財産で決済した場合は、取消しが制限されることがあります。

第4章 利用者の義務

第12条（禁止行為）

利用者は、次の行為をしてはなりません。

  1. マクロ、自動入力プログラム、自動タッチ装置など、人が直接操作せずに入力を自動で繰り返したり代行したりする手段を使う行為
  2. 改ざん・改造されたアプリ、メモリ・保存データ・通信内容を書き換えるツール、ゲーム速度を変更するツールを使う行為
  3. 端末の時刻変更など、不正な方法でゲームの数値や記録を操作する行為
  4. ゲームのバグやエラーと知りながら利用して利益を得る行為
  5. ランキングの記録を不正な方法で上げる行為、または他の利用者の正常な利用を妨害する行為
  6. 決済と返金を繰り返すなど、決済・返金の手続きを悪用する行為
  7. 固有名などに、他人の権利を侵害する表現や、暴言・差別的・わいせつな表現を使う行為
  8. 本ゲームを分解・複製・改ざんする行為、またはサーバーに不正にアクセスする行為
  9. その他関係法令に違反する行為、または本ゲームの正常な運営を妨害する行為

第13条（エラーの報告）

利用者は、バグやエラーを見つけた場合、それを利用せず、当社へメールでお知らせください。

第5章 利用制限と異議申立て

第14条（利用制限）

  1. 利用者が第12条に違反した場合、当社は、警告、ランキング記録の削除またはランキングからの除外、不正に得たゲーム内の財貨・記録の回収、期間を定めた利用制限、期間を定めない利用制限（以下「無期限制限」）のいずれかの措置を行うことがあります。
  2. 措置の種類と期間は、違反の内容、程度、回数、結果を考慮して定めます。
  3. 第12条第1号から第3号までの行為（自動入力手段、改ざんツール、数値操作）は本ゲームの公平性を著しく損なうため、初めて確認された場合でも無期限制限を行うことがあります。
  4. 当社は、プレイ記録を自動で分析して不正プレイを検知することがあり、検知した場合は事前の通知なく利用を制限することがあります。
  5. 検知基準の詳細は、悪用を防ぐため公開しません。
  6. 不正プレイで得た記録によって受け取った称号と報酬は、回収することがあります。

第15条（制限の通知）

  1. 本ゲームは会員登録を行わないため、当社は利用者に個別に連絡することができません。利用が制限された場合は、ゲーム画面に制限の事実、理由の要旨、アカウントコード、問い合わせ先のメールアドレスを表示します。
  2. 利用者がメールで問い合わせた場合、当社は制限の種類、期間、理由の要旨をお知らせします。

第16条（異議申立て）

  1. 利用者は、利用制限に異議がある場合、制限の事実を知った日から30日以内に、アカウントコードと異議の理由を記載して当社へメールで異議を申し立てることができます。
  2. 当社は、異議申立てを受けた日から15日以内にプレイ記録を再検討し、結果をメールで回答します。この期間内の回答が難しい場合は、その理由と処理予定日をお知らせします。
  3. 検討の結果、正常なプレイであると確認された場合、当社は直ちに制限を解除し、制限に関して保存した情報を削除します。

第17条（制限されたアカウントの有料商品）

  1. 期間を定めた利用制限の場合、有料商品は返金せず、制限期間の終了後に再び利用できます。
  2. 無期限制限の場合、制限日の時点で決済日から7日が経過していない有料商品の決済金額は返金します。決済日から7日が経過した有料商品は返金しません。
  3. 第2項にかかわらず、関係法令により返金が必要な場合は返金します。
  4. 第16条により制限が解除された場合、有料商品は元どおり利用できます。
  5. 返金の手続きは第9条第3項に従います。
